# 生徒・保護者登録フォーム

`touroku.html` が本番登録フォームの正本です。送信先の既存Apps Script WebアプリURLは変更しません。

## 2026-09-27 生徒マスタ自動設定

登録フォームに必須の「通塾教室（神領・大手・その他）」を追加しました。Apps Script側では新規登録行に限り、次を自動設定します。

- A列: A列の最大生徒番号 + 1（`LockService` による排他制御）
- B列: 在籍フラグ `1`
- C列: 登録日
- H列: 通塾教室
- J列: I列の生年月日から年度に応じて自動進級する数式
- L列: フリガナをローマ字化した先頭4文字
- AZ列: `STEP-` + 生徒番号

GAS正本は `gas/registration_backend.gs` です。スプレッドシートに紐づく既存Apps Scriptの `registerStudent(data)` と関連ヘルパーをこのコードで更新し、既存Webアプリのデプロイを新バージョンへ更新してください。
